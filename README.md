# Fortune Cookie for an AI Agent

Entry for the make.fun bounty [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

A small deterministic program that writes one fortune-cookie line for an AI agent to `/output/entry.txt`. No network, no dependencies — the same bytes on every run.

## Run

```sh
npx tsx main.ts
```

The fortune is written to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
